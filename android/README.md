# AnonBox Android

Application Android légère qui ouvre directement l’espace privé AnonBox.

- URL propriétaire prévue : `https://nadmit21-ux.github.io/AnonBox/?app=1`
- Min SDK : Android 8.0 (API 26)
- Connexion et messages : Supabase via l’interface web AnonBox
- Choix d’image/logo : pris en charge par le sélecteur de fichiers Android
- Liens externes : ouverts avec les applications du téléphone

Le workflow GitHub Actions `anonbox-android.yml` compile l’APK et publie la dernière version sous le tag `anonbox-latest`.
